Contact and feedback

Anemone is developed in the open. The best way to reach us is a GitHub issue: it is public, so others with the same question can find the answer.

  • Found a factual mistake, a broken link or a confusing question? Please say which page and what is wrong, and add a source if you can.
  • Translation problem? Every page in a non-source language has a "Suggest a translation fix" link.
  • Accessibility barrier? Tell us what device or assistive technology you use and where you got stuck.
  • Want to contribute a lesson or a language? The README explains the data format and the checks.

Please do not put personal data in an issue.
